1. モンスターの変更

30→35% カリングストライク閾値 通常敵の最大ライフ％
統一 モンスターのリーチ耐性 全レアリティ共通値に
対象 エッセンスパック Pack Size 影響下に

全体調整

  • 通常敵に対するカリングストライク（Culling Strike）の閾値が、最大ライフの35%に引き上げ（旧 30%）
  • モンスターのリーチ耐性は、以前より遅いレベルから始まり、各レベルでの値も低下。全モンスターレアリティで同じリーチ耐性量に統一
  • エッセンス・モンスターパックが、Pack Size（パックサイズ）モディファイアの影響を受けるようになった
  • モンスターから放出されたアズメリ・スピリットは力を保持し、同じモンスターから放出された他のスピリットを強化するようになった

個別モンスター修正

対象変更内容
プリースト・オブ・ザ・サン 放つビームが一部の壁を無視していた不具合を修正
ヴァイパー・ナプアツィ 兵士たちがアリーナを縮小した際に、フラスコチャージを一部回復するようになった
バーニング・デッド（オーガム村） ダメージの一部を火属性として与えるように（従来は純粋な物理）
ライトニング・ドリヤニ（エリートモンスター） ビジュアルとテレグラフ（攻撃予兆）が改善
設計意図 リーチ耐性のレアリティ統一はライフリーチ系ビルドの基準を読みやすくするための調整。エッセンスがパックサイズ影響下に入ったことで、エッセンス周回の物量効率が変化する。

2. クエストの変更

  • プランダーズ・ポイント は、キングスマーチ で4 つの地図の断片すべてを納品するまで進入できなくなった
  • 死者の広間 で ナヴァリ と対話した際、Greater Mind Rune（グレーター・マインドルーン）を受け取るようになった（従来は Lesser Mind Rune）
  • すでに リス を解放済みの場合、裏切り者の通路 へ到達するために ハラニ門 を訪れる必要がなくなった
序盤導線の整理 Risu 解放済みプレイヤーに対する Halani Gates 経由の冗長な往復を削除し、キャンペーン進行のテンポ改善を狙った変更。Plunder's Point のゲーティング追加は、地図の断片収集のクエスト的意味付けを明確化する。

3. ユーザーインターフェースの変更

アクセシビリティ・入力

  • UI ポップアップのサイズを拡大するアクセシビリティ設定を、オプションパネルの UI セクションに追加
  • ドッジロール専用キーバインドを追加。長押ししてもスプリント（疾走）に切り替わらない。デフォルトは未割り当て
  • マウス＆キーボード使用時、ハイドアウトの装飾品リストに 「Show Only Available（所持品のみ表示）」 オプションを追加
  • クリック移動使用時、移動中に使用可能なチャネリングスキルの詠唱が、クリック移動で中断されなくなった

マップ・スキル表示

  • Act 1〜3 のワールドマップについて、ビジュアルの視認性、ロード時間、パフォーマンスを改善。エリアレイアウトのゲーム内方向と一致するよう修正
  • スキル情報ポップアウトで、修正されたステータスをパネル最上部に並べる挙動を廃止。引き続き青色でハイライト表示される
  • マーチャント・タブ・ショップ のアイテム売却通知で、異なるリーグのアイテムが売れた場合は別メッセージを表示
  • 儀式 UI のリロールボタンが、無料リロール残数がある場合に脈動表示されるようになった
  • エンパワーされたミニオンが、モンスターに表示される 「Minion（ミニオン）」テキストを更新するようになった

キャラクター・アイテム情報

  • 増強物スタッシュタブ を更新し、5 つのセクション構成に変更
  • エネミーをマークすると、ライフバー上にマークが表示されるようになった
  • キャラクターパネルに、最大レイジ、レイジ喪失遅延、毎秒レイジ喪失量を表示
  • 検索テキストボックスの最大文字数を 250 文字に拡張
  • アイテムテキストのコピー時、常に詳細表示形式で出力されるようになった
  • アイテムテキストでの検索も、詳細表示形式に一致するようになった

トレード・コスメ

  • マウス＆キーボード使用時、通貨交換所 でお気に入りトレードを設定可能
  • 追跡スクロール をソーシャルプロフィールにピン留めし、フレンド、ギルド、パーティメンバーに表示可能
  • 該当する武器種を装備していなくても、コスメティックショップでマイクロトランザクションの武器スキンをプレビュー可能に

コントローラ対応

  • ハイドアウト編集用の俯瞰カメラビューをコントローラ向けに追加
  • 現在適用中の Currency をすばやく切り替える 機能を追加
  • 通貨交換所 UI をコントローラ向けに刷新
  • アイテムやインタラクト可能オブジェクトのターゲット選択を改善

システム全般

  • オプションメニューを更新・再構成
  • PlayStation および Xbox でゲーム内時計オプションを有効化

4. マイクロトランザクションの変更

既存のマイクロトランザクション（MTX）アイテム群が PoE2 でも利用可能化（Enabled）。本セクションは「すでに PoE1 などで購入済のオーナー向けに、PoE2 でも装備可能にした」という性質の変更。
